Replaces vanilla heart and food icons with clean, theme-aware progress bars and percentage text.

---

## What this mod does

- Replaces the vanilla **Health**, **Mana**, and **Food** icons with sleek progress bars
- Adds a **mana icon** on the mana bar
- Shows **hover tooltips**
- Matches your selected **Interface Style** (theme-aware)
- Includes **percentage text** for quick readability

---

## Installation / Requirements

- **Client-side only** (players install it)
- Servers do **NOT** need this mod
