# Steam Workshop text for StatusForge 1.1

Paste the description into the update box in the game. Steam uses BBCode, not Markdown.

## Title

StatusForge (Client-Side)

## Description

```
[h1]StatusForge[/h1]
Replaces the vanilla heart and food icons with clean progress bars and percentage text.

[h2]What it does[/h2]
[list]
[*] Replaces the vanilla [b]Health[/b], [b]Mana[/b] and [b]Food[/b] icons with progress bars
[*] Adds a mana icon on the mana bar
[*] Hover tooltips on every bar
[*] Matches your selected Interface Style
[*] Percentage text for quick reading
[*] [b]Always show values[/b] mode. Press [b]F8[/b] (rebindable under Controls) to show the numbers on every bar at all times. Your choice is saved
[/list]

[h2]Optional: SettingsForge[/h2]
If you also install [url=https://steamcommunity.com/sharedfiles/filedetails/?id=SETTINGSFORGE_ID]SettingsForge[/url], Always show values appears as a checkbox under Settings, Mod Settings. You do not need SettingsForge. Without it everything works as before and F8 still toggles the values.

[h2]Requirements[/h2]
[list]
[*] Client-side only, servers do not need it
[*] Built for Necesse 1.3.3
[/list]

[url=https://github.com/Kkthnx-Necesse/StatusForge]Source on GitHub[/url]
```

Replace SETTINGSFORGE_ID with the item id once SettingsForge is uploaded.

## Change note for 1.1

```
Updated for Necesse 1.3.3.
Buff icons and the HUD click-through area now follow the StatusForge bars.
New key (F8) to show health, mana, resilience and food values at all times. The choice is saved.
Bars are clamped to 0-100 percent and tooltip text is only built while hovering.
Optional SettingsForge support: Always show values also shows as a checkbox under Settings, Mod Settings when SettingsForge is installed.
```
